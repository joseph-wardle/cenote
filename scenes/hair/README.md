# Groom benchmark scenes

The two curve-geometry benchmark scenes: `straight.ron` (10,000 strands,
the first real groom) and `curly.ron` (50,000 strands / 20.35 M swept
triangles, the hero the curve gates are set against). Both frame the
groom alone so every millisecond of traversal they report is hair.

The grooms themselves are Cem Yuksel's hair models — free for research
with attribution, **not to redistribute** — so only these RONs are
tracked. Fetch `straight.hair` and `wCurly.hair` from
<http://www.cemyuksel.com/research/hairmodels/> into `sources/` here.
